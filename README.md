# Portfolio — Paul Glatt

Portfolio personnel de Paul Glatt, Développeur Web. Le projet est construit avec React et Vite.

## Prérequis

- Node.js LTS
- npm

## Démarrer en local

```bash
npm install
npm run dev
```

Vite indique ensuite l'adresse locale (généralement http://localhost:5173).

## Vérifier la version de production

```bash
npm run build
npm run preview
```

Le site compilé se trouve dans `dist/`.

## Déploiement statique

Le projet peut être déployé sur Vercel, Netlify ou un hébergement statique compatible.

Pour Vercel :
- Framework : Vite
- Build command : `npm run build`
- Output directory : `dist`

## Structure

- `src/main.jsx` : contenu, composants, navigation et thème.
- `src/style.css` : identité visuelle, thèmes clair/sombre et responsive.
- `public/CV-Paul-Glatt.pdf` : CV téléchargeable.
- `docs/` : notes de projet.
