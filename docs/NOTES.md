# Notes de conception

## Intention

Présenter un profil de développeur concepteur d'applications en début de parcours professionnel, sans gonfler artificiellement l'expérience. Le contenu suit le fil d'un projet numérique : comprendre, concevoir, développer l'interface, structurer le back-end et organiser le code.

## Direction visuelle

Le projet conserve la composition expressive de la première version React : grand hero typographique, composition graphique, ruban horizontal, sections éditoriales et cartes de projets. Le vert a été retiré. La palette combine corail, violet et bleu clair sur une base graphite, avec une déclinaison claire ivoire.

## Transparence

- Les projets Altitude Rénovation et Byfect sont liés vers leurs sites.
- Les visuels sont des illustrations éditoriales, non des captures d'écran.
- L'ERP est présenté sans capture, code, données ni information client.
- Le Home Lab est un projet d'apprentissage en préparation.
- Le CV présent dans `public/` est extrait du PDF intégré dans le portfolio HTML fourni.
